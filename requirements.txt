# ============================================================================
# PetroQuery — runtime dependencies (core)
# ============================================================================
# This file lists the dependencies that run PetroQuery's HTTP API,
# authentication, and database layer. It is intentionally cross-platform
# (Linux / macOS / Windows) and CPU-only — no CUDA wheels.
#
# The RAG ML stack (embeddings, cross-encoder, PDF parsing) lives in
# `requirements-ml.txt` and must be installed on top of this file when
# the API needs to serve real RAG requests:
#
#     pip install -r requirements.txt
#     pip install -r requirements-ml.txt      # only on hosts that run RAG
#
# On Windows + Python 3.12 the default PyPI index already serves
# CPU-only wheels for torch (>= 2.3). CUDA wheels are not required for
# the API server; they are reserved for training hosts and are NOT
# pinned here on purpose.
# ============================================================================
